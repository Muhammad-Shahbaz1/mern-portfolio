# Muhammad Shahbaz – MERN Stack Developer Portfolio 🚀

A modern, high-performance, and responsive personal portfolio website built with the **MERN Stack** (MongoDB, Express.js, React, Node.js), **Tailwind CSS**, and **Google Gemini AI**.

---

## 🌐 Live Demo
🔗 **[Live Portfolio Website](https://github.com/Muhammad-Shahbaz1/mern-portfolio)**

---

## 💻 Tech Stack

- **Frontend:** React.js (Vite), Tailwind CSS v3, Framer Motion, React Icons, React Scroll
- **Backend:** Node.js, Express.js, REST APIs, Nodemailer
- **AI Integration:** Google Gemini Flash API (`@google/genai` serverless functions)
- **Deployment:** Netlify (Frontend & Serverless Functions) / Railway

---

## ✨ Key Features

- ⚡ **High-Performance & Modern UI:** Sleek dark-mode aesthetic with smooth scroll-reveal animations and glassmorphism.
- 🤖 **Embedded Portfolio AI Assistant:** Interactive AI chat powered by Google Gemini trained on Muhammad Shahbaz's technical background, projects, and contact info.
- 💼 **Featured Projects Showcase:**
  - ⚖️ **Lexora — AI Legal Document Companion:** AI-powered contract analysis platform that scans legal documents (PDF/Images) to detect hidden risks, flag unfair terms, generate bilingual breakdowns (Roman Urdu/English), and provide negotiation tips.
  - 🏥 **HealthMate – Sehat ka Smart Dost:** AI-powered bilingual medical vault & health assistant analyzing medical reports (PDF/Images) in Roman Urdu & English with abnormal value detection and vitals timeline.
  - 🚀 **PitchCraft AI:** 10-slide investor pitch deck builder with market sizing (TAM/SAM/SOM), PowerPoint (.pptx) & PDF exports.
- 📱 **Fully Responsive:** Pixel-perfect layout across mobile, tablet, laptop, and desktop viewports.
- 📩 **Functional Contact Form:** Automated email dispatch via Nodemailer backend integration.
- 🛠️ **Developer Activity & Skills Matrix:** Categorized frontend, backend, database, and tool competencies.

## 📂 Project Structure

```text
mern-portfolio/
├── frontend/                  # React (Vite) Application
│   ├── public/                # Static assets & project preview images
│   └── src/
│       ├── components/        # Reusable UI & section components
│       │   ├── chat/          # Floating AI Assistant component
│       │   ├── common/        # Buttons, cards, modals, headings
│       │   ├── layout/        # Navbar & Footer
│       │   └── sections/      # Hero, About, Skills, Projects, Contact, etc.
│       ├── data/              # Single source of truth (portfolioData.js)
│       └── index.css          # Design system & Tailwind styling
├── backend/                   # Node.js & Express.js server (Nodemailer API)
├── netlify/                   # Netlify serverless functions (Gemini AI chat)
├── netlify.toml               # Netlify build & routing configuration
└── start.bat                  # One-click local launch script
```

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Muhammad-Shahbaz1/mern-portfolio.git
cd mern-portfolio
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup (Optional for Contact Form)
```bash
cd ../backend
npm install
node server.js
```
